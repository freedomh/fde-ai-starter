# 空电脑准备

课堂按 Windows + PowerShell + Docker Desktop 的路线准备。Mac/Linux 学员可以使用同样的容器源码与 Compose，但本仓库的启动辅助脚本是 PowerShell，不能直接当作 bash 运行。

## 课前安装

1. 安装 Git：[Git 官方 Windows 下载](https://git-scm.com/download/win)。安装完成后新开终端，确认 `git --version`。
2. 安装 Docker Desktop：[Docker 官方 Windows 安装说明](https://docs.docker.com/desktop/setup/install/windows-install/)。按官方系统与虚拟化要求启用 WSL 2 / Linux 容器模式；可能需要管理员操作和重启，应在课前完成。
3. 打开 Docker Desktop，完成它要求的人为设置，等待引擎启动。安装完成不等于引擎正在运行。
4. 准备能打开本地工程并执行终端命令的 AI 编码工具。网页聊天工具也可使用提示词，但需要自己把代码存成文件和执行命令。

```powershell
git --version
docker version
docker compose version
docker info --format '{{.OSType}}'
```

最后应看到 `linux`，且 docker version 包含 Server 信息。遇到缺项，把 docs/课程提示词.md 的“01 空电脑准备”发给 AI，不要凭猜测安装一堆运行时。

## 克隆与运行

```powershell
git clone https://github.com/freedomh/fde-ai-starter.git my-ai-project
cd my-ai-project
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Local.ps1
```

Docker 会在容器内准备 Node、Java、Maven、MySQL、Redis。首次构建需要网络、磁盘和时间；课程开始前先完整构建一次。若镜像/依赖下载失败，应按实际错误诊断网络，不关闭 TLS 检查或安全软件来掩盖问题。

## 不需要做的全局安装

全容器路线不要求把 Node/JDK/Maven/数据库直接安装到 Windows，也不要求改系统 Java 默认版本。需要宿主机热更新开发时，再按该工程版本单独配置，不与首次 Docker 跑通混在一起。
