# 演示项目：课程反馈台

一个本地单人使用的课堂项目。教师在管理端录入课堂表现，把文本整理成草稿，编辑确认后，学员端才能看到反馈。所有姓名和内容是虚构练习数据。

## 为什么适合演示

- 前台和管理端都有明确用途，能展示同一 Java 服务支撑两种页面。
- 三张表覆盖真实的关联保存、唯一关联、状态转换与数据持久化。
- DRAFT → CONFIRMED 的变化在两个浏览器页面都能立即观察。
- Redis 缓存统计，MySQL 保存业务记录，Docker 一次启动所有依赖。
- 无需付费模型 Key：本地模板生成草稿，演示重点是“AI 如何开发项目”；不能把模板说成模型生成。

## 10 分钟现场操作

1. 打开教师管理端与学员前台，选同一位演示学员。
2. 管理端录入主题“分数应用题”、课堂表现和课后任务。
3. 点击生成草稿。查看 DRAFT 状态与“本地模板”说明；刷新学员端，仍没有这份反馈。
4. 将草稿里的建议改成自己的话，保存并确认。
5. 刷新学员端，核对同一份已确认内容；查看统计变化。
6. 再次确认不会多一份；已确认内容不能继续改。
7. 保留数据卷重启容器，核对记录和状态仍在。

完整需求、代码和验收脚本位于 `demo/class-feedback` 分支。
