验证环境：Windows / PowerShell + Docker Desktop Linux 容器；不代表所有学员电脑环境或生产环境已经通过。

- Docker 多阶段构建：两个 Vue 工程分别执行 npm ci 与类型/构建检查，后端运行 mvn verify。
- 后端 7 个测试通过：2 个依赖健康检查测试、5 个业务状态/校验/缓存测试。测试使用 H2 和 Redis mock，另外进行真实容器验收。
- 实际 MySQL 8.0.42 / Redis 7.2.8 与两个 Nginx 页面启动可用。
- Verify-Demo.ps1 -CheckRestart 通过：草稿不显示于学员端、草稿唯一、幂等确认、确认后编辑 409、空白输入 400、不入库、保留卷重建后的相同反馈仍在。
- 实际浏览器完成虚构课堂记录→生成草稿→编辑→确认→学员端刷新看到相同内容。

本地模板整理是可重复的演示逻辑，不调用外部大模型。Redis 的短期统计缓存不保证高并发强一致。没有真实账号鉴权、生产发布或其他操作系统运行验证。
